# El Círculo — Wall Street para latinas

Landing page de la comunidad privada de @alexandra.invierte.

## Archivos
- `index.html` — la página (este es el archivo principal)
- `styles.css` — estilos
- `app.js` — ticker, gráficas y animaciones
- `worldmap.js` — mapa global interactivo
- `alexandra.jpg` — foto del hero

## Cómo publicarlo gratis en GitHub Pages
1. Crea un repositorio nuevo en GitHub (p. ej. `el-circulo`).
2. Sube TODOS los archivos de esta carpeta (arrástralos a la página del repo → "commit").
3. En el repo, ve a **Settings → Pages**.
4. En "Source" elige la rama **main** y la carpeta **/ (root)**. Guarda.
5. Espera ~1 minuto. GitHub te dará la URL pública: `https://TU-USUARIO.github.io/el-circulo/`

Como el archivo se llama `index.html`, la página cargará sola con esa URL — no hay que escribir el nombre del archivo.

## Cambiar la foto
Reemplaza `alexandra.jpg` por otra imagen con el mismo nombre (formato vertical recomendado).

## Nota
El botón "Entrar" apunta a tu enlace de pago de Stripe. Si cambia, edítalo en `index.html` (busca `buy.stripe.com`).
